About

Bridging academia and industry practice

PN

I'm Praveen N, an Assistant Professor at NIPE, focused on teaching and mentoring students in modern backend technologies, database systems, and cloud deployments. My courses integrate hands-on labs with theoretical foundations, so students build a working intuition for the systems they're studying — not just the vocabulary.

Across semesters, I've designed and run curricula spanning web frameworks, algorithm design, and infrastructure automation, with an emphasis on reproducible labs, real tooling, and assessment that mirrors industry practice.

  • Python · Flask & Django web development
  • Object-oriented & object-based databases
  • MongoDB, XML, XQuery & NoSQL systems
  • Cloud database deployment — AWS & GCP
  • Algorithm design & complexity analysis
  • Windows PowerShell & Azure automation (DSC)
